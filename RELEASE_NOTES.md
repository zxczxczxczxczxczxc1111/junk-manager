Junk Manager 0.1.1

Что изменилось:

- Добавили очистку кэша прослушивания Spotify, а также больше кэшей приложений, игр и инструментов разработки. После очистки Spotify загрузит музыку заново; вход, настройки и плейлисты сохранятся.
- Добавили раздел «Место на диске». Он показывает размеры папок приложений и Windows, помогает найти крупные файлы и сохранить отчёт в CSV. Подсчёт ничего не удаляет.
- Исправили удаление переносимых программ, установленных через WinGet, в том числе Bun и WinLibs. Раньше они появлялись в списке, но выбрать их было нельзя.
- Исправили зависание при сборке большого списка находок. Кнопка остановки теперь работает и на этом этапе, а подпись показывает, чем занято приложение.

Для запуска скачай **JunkManager.exe**. Установка и отдельный .NET не нужны. **JunkManager.Cli.exe** нужен только для работы из командной строки.

Проверено на Windows 11 x64. Интерфейс на русском языке.

По умолчанию файлы удаляются без корзины. Режим удаления и необязательные резервные копии записей реестра можно выбрать в настройках.

Сборка пока не подписана. Windows может показать предупреждение при первом запуске.

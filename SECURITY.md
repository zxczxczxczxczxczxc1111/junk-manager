# Сообщить о проблеме безопасности

Если нашёл способ удалить файлы вне выбранной области, обойти проверку пути или выполнить постороннюю команду, не прикладывай рабочий способ эксплуатации к публичному issue.

Используй «Report a vulnerability» во вкладке Security, если эта кнопка доступна. Если её нет, создай issue с просьбой связаться приватно, без подробностей эксплуатации и личных данных.

Для разбора полезны версия приложения, версия Windows, описание ожидаемого и фактического поведения. Проверяй воспроизведение в отдельной виртуальной машине.

Исправления выпускаются для текущей версии приложения. Старые сборки отдельно не поддерживаются.
